Link that doesn't open a board

Links are never revoked; to stop sharing, people clone the board. A link can still be mistyped or cut short, so the page says what to check.

Check that you copied all of it: a mapcro link ends with a long code after “#”. If it's right, ask whoever sent it for a fresh one.
