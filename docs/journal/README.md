# Journal

A dated record of how mapcro gets built: decisions, experiments, surprises, and what each one
taught us. The operator asked for it so the project can be learned from, not just used.

Entries are append-only. A later entry may correct an earlier one, but never rewrites it. Each
experiment writes its predictions down *before* it runs, so the result can show whether they held.
