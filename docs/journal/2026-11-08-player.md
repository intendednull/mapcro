# 2026-11-08: Player

The operator reframed match import: a board with a match opens in **Player**, which plays the match
on the map; Sandbox is the scene editor; the landing page has **Open match** and **New board**.
Spec §6b holds the design. This is what building it taught us.

## Decisions

- **Player draws only the timeline, Sandbox only the scene.** The operator saw heroes drawn dark
  that weren't dead: the old preview took the match's positions but the scene's alive, seen and
  placed flags. Tokens, objectives, rifts and waves now take everything from the match under a
  preview, and an e2e test covers switching modes and scenes both ways.
- **The board's matches live beside it on the server,** not in its document (no schema change
  for attaching one).
- **Annotation over playback is a hidden "live" scene** (operator: annotate live, keep it by
  saving a scene). Every tool works unchanged, shared live like any record; Save scene moves the
  records into the new scene in the same transaction; the last person to leave Player clears
  the rest. The cost: those records pass through the board's history.
- **Following carries playback in presence** (mode, match, t, playing, speed), sent on change and
  every 2 s while playing; a follower within 0.75 s of the presenter keeps its own clock.

## Surprises

- **`ImportantAbilityUsed` isn't the ult.** It fired 799 times in a 15-minute match. An ult is now
  the rise of the hero's ult cooldown, named by the message within two seconds before: 41.
- **Souls swings from coarse samples are mostly timing.** Players' net worth updates land a few
  seconds apart, so one team "swings" until the other's arrive. A swing must hold ten seconds on,
  and none count in the first two minutes.
- **Search words match independently,** so "hero 20 died" also finds deaths at 3:20. Kept: it's
  what a filter box usually does; adding the time narrows it.
- **The shared box** held builds for long stretches (another project's verify). Working in clean
  worktrees let the security fixes and Player be tested apart from other agents' half-done edits.
