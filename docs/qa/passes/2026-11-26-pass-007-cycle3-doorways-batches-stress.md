## Process Meta-Notes (Mandatory — Evaluating `tools/qa-browser/` v1.6 & Proposals for v1.7+)

- **What worked great in v1.6:**
  - `resize <tab> <WxH>` (`615x344`, `667x375`, `844x390`, `360x800`, `1024x768`) matched `open --viewport` seamlessly and sped up the 4-viewport touch sweep dramatically.
  - Running `tools/qa-browser/qa-browser.mjs` directly with system `node` after initial `nix develop -c ... start` eliminated ~2 s of Nix shell overhead per CLI call, making parallel two-user race stress tests fast and genuinely concurrent.
  - Visual screenshot inspection (`read_file` on `/tmp/qa-pass-007/*.png`) directly exposed all 3 new findings — especially `games-sheet` staying stuck open across `Player → Scene` after `Escape` and the crushed `"F..."`/`"F.."` badge on `360×800` and `1024×768`!

- **Friction noticed in v1.6:**
  1. **No coordinate-based trusted click / right-click (`click-at` / `rclick-at`):** Map interactions like 2-step doorway placement and empty-map `map-menu` require trusted mouse clicks (`button: 0` and `button: 2`) at specific viewport `(x, y)` coordinates away from Mid-Boss/objectives. Synthetic `dispatchEvent(new PointerEvent(...))` fails `svg.setPointerCapture()`, forcing awkward workarounds (`drag x y x y --steps 1` for left-click, and `wheel` off-center + `rclick testid:map --force` for right-click).
  2. **No `scrub <tab> <seconds>` helper:** Every replay pass repeats the 6-line `HTMLInputElement.prototype.value` setter + `input`/`change` dispatch idiom inside `eval`.
  3. **No built-in layout/overflow audit command (`audit-layout`):** Checking horizontal/vertical overflow, `.p-top`/`.pl-bar` clipping, and off-screen interactive buttons required pasting a 25-line `eval` script on every viewport sweep.
  4. **Duplicate DOM hits from Scene hover thumbnails (`.mm-host.lite`):** When the pointer happens to rest over a Scene row in the sidebar, `document.querySelector('[data-key=...]')` matches the `.mm-host.lite` hover thumbnail before the main `.mm-host.free` map — nearly causing a false-positive sync divergence alert during Stress 6 until inspected!

- **Concrete upgrades proposed for `tools/qa-browser/` v1.7+:**
  1. **Add `click-at <tab> <x> <y>` and `rclick-at <tab> <x> <y>`** (using real `page.mouse.click(x, y, { button: "left" | "right" })`): unlocks clean, zero-hack map canvas interactions (doorway placement, empty-map `map-menu`, comment placement, erasing at exact points).
  2. **Add `scrub <tab> <seconds|mm:ss>`**: sets `[data-testid="match-time"]` via native value setter + dispatches `input`/`change` and returns the resulting `match-clock` text.
  3. **Add `audit-layout <tab>`**: returns `{ vw, vh, docOverflowX, docOverflowY, containers: [{ sel, overflowX, overflowY }], clippedInteractive: [...] }` in one compact JSON call, skipping horizontally scrollable `.events-chips` rows so real header/bar clips (like Finding #1) pop out immediately on every viewport sweep.
  4. **Add `docs/qa/README.md` false-positive note:** Always scope main-map queries under `[data-testid="map"]` (never bare `document.querySelector('[data-key=...]')`) so `.mm-host.lite` scene-row hover thumbnails never masquerade as stale main-map objectives.
