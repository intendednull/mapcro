## Process Meta-Notes (Mandatory)
- **Friction in `tools/qa-browser/`:**
  1. **`.first()` hits hidden duplicate DOM nodes:** `click`, `fill`, and `hover` call `locator(sel).first()`, which repeatedly timed out (10 s each!) when an earlier hidden desktop/phone duplicate existed in the DOM (e.g., `testid:match-id`, `button:has-text("All builds")`, `button:has-text("Scenes")`). Workaround was appending `>> visible=true`, which shouldn't be required manually.
  2. **`snapshot` reports CSS-hidden popover children as visible & omits `<summary>`:** `snapshot` listed `[data-testid="match-id"]`, `[data-testid="heals-toggle"]`, etc., inside closed popovers (`visibility: hidden` / `opacity: 0`) because it checks non-zero `getBoundingClientRect()` without checking `getComputedStyle(el).visibility !== "hidden"` or `opacity !== "0"`. Meanwhile, `<summary>` (`Match source ▲`) was omitted from `snapshot`'s interactive list entirely!
  3. **Map token click interception:** Clicking `[data-testid=map] .mk` directly failed because the `<svg class="mm-overlay map">` `.notes-area` rect sits above `.mk` in pointer hit-testing; had to inspect via portrait/DOM instead.
- **Blind spots / coverage gaps noticed:**
  - `process-log.md` v1 Prediction #1 (**Narrow desktop & visual overlap bugs**) was **strongly confirmed** — 5 of our findings were visual/layout overlaps at `1024×600`, `800×600`, and `1024×768 --touch` that automated e2e completely missed!
  - Prediction #2 (**State-transition bugs**) was **partially confirmed** (stale skull recap across scrub/Scene switch, stale `Back to replay` toast).
  - Visual screenshot inspection via `read_file` was the single highest-value step; DOM metrics alone would have missed the `Map layers` z-index occlusion behind TopBar portraits, the `All builds` text collision, and the tablet `Scenes` drawer overlap.
- **Suggested upgrade for next pass:**
  - **Upgrade `tools/qa-browser/daemon.mjs` (high-impact, ~15 lines):**
    1. Default `click`/`fill`/`hover`/`dblclick`/`rclick` to `page.locator(sel).filter({ visible: true }).first()` (with a `--any` fallback if ever needed) so hidden desktop/phone duplicates never cause 10 s timeouts.
    2. In `snapshot`, include `summary` in the interactive selector list and filter out elements with `getComputedStyle(el).visibility === "hidden"` or `opacity === "0"`.
