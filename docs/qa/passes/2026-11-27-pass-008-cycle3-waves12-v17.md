## Process Meta-Notes (Mandatory — Candid Evaluation of `tools/qa-browser/` v1.7 & Proposals for v1.8)

- **What was a massive win in v1.7:**
  - **`click-at`, `rclick-at`, and `dblclick-at`** completely eliminated Pass 007's pointer-capture hacks! Every `#55` `obj-menu` right-click, short-click objective toggle, `#16` minimap token double-click, `#61` paused `map-menu-doorway` placement, and Block E negative view-only doorway test worked on the very first try with real trusted pointer events.
  - **`scrub <tab> <mm:ss>`** turned a 6-line `HTMLInputElement.prototype.value` `eval` boilerplate into a single readable command returning `{ ok, seconds, clock }` — used 15+ times across `129738985` and `142815246` with zero hiccups.
  - **`offline <tab> on|off`** made the durable edit queue & reconnect charter effortless — immediately surfaced `save-status: "Syncing 4"` while offline and verified clean flush to `"Saved"` + 2-tab convergence on reconnect.
  - **`audit-layout <tab>`** made the multi-viewport `FM-130` & Pass 007 touch sweeps (`360×800`, `390×844`, `615×344`, `768×1024`, `1024×768`) dramatically faster and caught off-scroll `.p-tools` / `.p-rail-tools` structure immediately.
  - **Visual screenshot inspection (`read_file`) remains irreplaceable:** `audit-layout` reported `0` overflow on `1440×900` during `#61`, while inspecting `issue61-paused-edits.png` instantly revealed Finding #1 (`+` speed button overlapping `15:55 / 25:14` by `30 px`).

- **Friction & bugs found in `tools/qa-browser/` v1.7:**
  1. **`audit-layout` dumps ~42 KB of off-scroll desktop Events rows (`OL.pl-list`) and flags intentionally scrollable horizontal tool rails (`.p-tools`, `.p-rail-tools`) + subpixel `-0.5 px` edges:**
     - `audit-layout` only skips `.events-list` / `.p-sheet-body` / `.events-chips`, missing desktop Events' actual scroll container (`OL.pl-list`), causing huge JSON output on desktop Player.
     - It flags off-scroll buttons inside `overflow-x: auto` tool strips (`.p-tools` in Phone Scene Edit mode, `.p-rail-tools` in `615×344` Player Edit mode) as `clippedInteractive`.
     - Strict `< 0` viewport checks trigger false positives on subpixel `-0.5 px` top edges (`games-open` / `follow-presenter` at `y: -0.5` on `360×800` & `1024×768`).
  2. **`normalizeSelector` breaks `testid:` values containing spaces:** `'testid:follow-Coach A'` expanded to `[data-testid="follow-Coach"] A` because the shorthand regex stops at whitespace, causing a 15 s timeout until rewritten as `[data-testid="follow-Coach A"]`.
  3. **`wait <tab> <selector>` does not use visible-first filtering (unlike `click`/`fill`):** `wait coachA 'testid:match-id'` resolved to a hidden `<input>` inside closed `<details>` and timed out, even when a visible match exists elsewhere.
  4. **`drag` only supports left mouse button (no `--button right|middle`):** Desktop right-drag map panning (e.g. `#16` pan-dismiss in desktop Select mode) cannot be driven via `drag` without dropping to `eval` or testing touch pan on `--touch`.
  5. **`audit-layout` doesn't check sibling collisions inside transport/header bars:** Sibling overlaps inside CSS grids (`speed-up` overlapping `match-clock` in `.pl-bar` with `overflowX: 0`) go undetected unless checked explicitly or caught visually.

- **Concrete upgrades proposed for `tools/qa-browser/` v1.8:**
  1. **Make `audit-layout` ancestor-aware + 1 px subpixel tolerance + optional sibling-overlap check:** Instead of hardcoding `.events-list`/`.events-chips`, skip any element clipped inside *any* ancestor with `overflow-x|y: auto|scroll` (while still verifying the scroll container itself fits in the viewport), apply a `1 px` tolerance (`< -1` / `> vw + 1`) to eliminate `-0.5 px` subpixel noise, and add pairwise sibling-overlap detection for `.pl-bar` and `.p-top` / `header.top` direct controls so bugs like Finding #1 surface automatically!
  2. **Add `--button <left|right|middle>` to `drag`:** Enables desktop right-drag map panning and middle-drag gestures cleanly.
  3. **Make `wait` visible-first by default (with `--any` opt-out)** to match `click` / `fill` / `hover`.
  4. **Quote/handle or warn on whitespace in `testid:`** (or document that IDs with spaces must use `[data-testid="..."]`).
